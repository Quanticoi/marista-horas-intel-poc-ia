pendências explícitas. [Cobertura funcional](../architecture/FUNCTIONAL_COVERAGE.md).

O [schema V1](planilha-turmas-poc-v1.schema.json) é mantido para propostas anteriores.
Ele não deve orientar novos consumidores da jornada V4.
